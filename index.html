SCSS foundation for a frontend system

Generic CSS

A base layer for building a design system. Design tokens, layout utilities and a set of components, all driven by variables you can override. Change the tokens and every component follows.

View on GitHub See the system
1. Tokens Colours, spacing, breakpoints, shadows and type in _variables.scss. All marked !default.
2. Utilities Reset, typography, grid, spacing, helpers, animation, off-canvas and print styles.
3. Components Button, label, alert, form, table, tabs, breadcrumb, navbar, dropdown, modal, pager and progress.

Make it yours

Set your own tokens before importing the library. Every component picks them up.

// your-theme.scss
$color-button: #7b2ed7;
$button-default-border-radius: 999px;
$font-base: 15;
$sm: 640px;

@import "generic-css/generic";
